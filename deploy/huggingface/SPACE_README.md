# Heat-Health Early Warning Platform

SIH 2026 · Problem Statement 26083 · Pilot city: Ahmedabad (48 wards).

Ward-level heat stress, vulnerability and mortality/hospitalization risk, with probabilistic early warning, safe work hours, cooling deserts, human-approved alerts, health-worker feedback and a what-if simulator.

- **Demo:** open the app with `?replay=may2024` to replay the May 2024 heatwave.
- **Labels:** all scores are model estimates, not clinical predictions. Health-worker reports in the demo are synthetic, and alert delivery is simulated.
- **Source code and documentation:** https://github.com/janhavitupe/Heat-Health-Warning-SIH
